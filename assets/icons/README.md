# NekoShelf — иконка

Сиреневая книжка-кот с кремовыми страницами и мятным значком скачивания.
Создана встроенным генератором изображений; PNG с прозрачным фоном.

- `neko_shelf-master.png` — исходное изображение генератора, 1254 × 1254.
- `neko_shelf-16.png`, `neko_shelf-32.png`, `neko_shelf-48.png`, `neko_shelf-128.png` — размеры для расширения.
- `neko_shelf-64.png`, `neko_shelf-256.png`, `neko_shelf-512.png` — дополнительные размеры для интерфейса и оформления.

Это готовые ассеты; userscript не изменён. Для использования в нём PNG можно встроить как data URL или разместить по постоянному HTTPS-адресу. На размере 16 px мелкие детали мордочки теряются.

Точный запрос генератору сохранён в `prompt.txt`. Уменьшенные копии экспортированы с сохранением прозрачности.
