## Что умеет

- **Скачивание тайтла** в один файл: выбираешь перевод, диапазон глав и формат.
  - Манга / манхва: **PDF** (по умолчанию), CBZ, ZIP, EPUB, HTML.
  - Ранобэ: **TXT** (по умолчанию), EPUB, FB2, PDF, HTML.
- **Своя читалка вместо 404** (сайты Lib). Некоторые тайтлы и главы сайт без входа в аккаунт уводит на «Страница не найдена», хотя сервер их отдаёт. NekoShelf в таком случае сам показывает главу или список глав.
- **Сведения о тайтле**: другие названия, автор, год, статус, жанры, теги, переводчик и ссылка на источник. В EPUB, FB2, CBZ (ComicInfo.xml) и PDF они записываются в метаданные файла, а в TXT, HTML, PDF ранобэ и ZIP — ещё и блоком в начале.
- **Имя файла** — `[Автор] - Название`: автор берётся из тега автора на сайте, из названия убирается всё в квадратных и круглых скобках, а символы, недопустимые в именах файлов (`\ / : * ? " < > | $ &`), заменяются на «-».
- Если вы вошли в аккаунт на сайте, скрипт подхватывает вход сам — так доступны и тайтлы, которые сервер отдаёт только авторизованным (например, 18+).
- Работает на компьютере и на телефоне (iPhone — через Userscripts).

## Установка

1. Поставьте менеджер userscript'ов:
   - **Chrome / Edge / Firefox:** [Violentmonkey](https://violentmonkey.github.io/) или [Tampermonkey](https://www.tampermonkey.net/).
   - **iPhone / iPad (Safari):** [Userscripts](https://apps.apple.com/app/userscripts/id1463298887) — после установки включите расширение в Safari.
2. Нажмите кнопку **«Установить»** выше — менеджер сам откроет окно установки.
   На iPhone: откройте ссылку в Safari, нажмите значок расширений в адресной строке → Userscripts → установить.

Обновления приходят автоматически из [релизов](https://github.com/Laynholt/neko_shelf/releases) — менеджер периодически проверяет новую версию.

## Как пользоваться

1. Откройте страницу тайтла на одном из сайтов — в углу появится кнопка с котиком-книжкой.
2. Нажмите её, выберите главы и формат, нажмите **«Скачать»**.
3. Чтобы пропустить отдельные главы внутри диапазона, раскройте «Выбрать главы в диапазоне» и снимите с них галки. Под каждой главой манги есть «Страницы» — там так же снимаются отдельные страницы (Shift+клик — сразу диапазон). У галерей из одной главы (Nude-Moon, IMHentai, nhentai) вместо списка глав сразу «Выбрать страницы».
4. Кнопку можно перетащить в удобное место — позиция запоминается.
5. Карандаш рядом с названием — своё название тайтла для файла. Шестерёнка — настройки (одинаковая ширина страниц в PDF/CBZ, обложка первой страницей) и вкладка «О скрипте».

Если основной сервер картинок не отвечает, NekoShelf спросит, брать ли картинки с запасного (они в AVIF и перекодируются в JPEG).

При HTTP 429 («слишком много запросов») скрипт сначала приостанавливает запросы и повторяет загрузку с того же сервера. Пауза берётся из `Retry-After`, если сервер его передал; иначе — минута перед первым повтором и две перед вторым. Остаток ожидания виден в панели, загрузку можно отменить. Только если повторы не помогли, появится предложение запасного сервера.

В настройках скачивания можно задать **задержку между запросами** в секундах (0–60). По умолчанию — **0**, без дополнительной паузы. Например, **0,5** разносит старты запросов скрипта как минимум на полсекунды, в том числе при параллельной загрузке картинок. Запросы самого сайта эта настройка не ограничивает и не гарантирует отсутствие 429 — лимит задаёт сервер.

## Для разработки

```bash
node neko_shelf.test.js
```

Новый релиз: поднять `@version` в шапке `neko_shelf.user.js`, затем

```bash
gh release create v1.0.1 neko_shelf.user.js --title "v1.0.1" --notes "Что изменилось"
```

Файл обязательно прикладывать к релизу под именем `neko_shelf.user.js` — по этому адресу менеджеры проверяют обновления.
